# 🧮 IPv4 Network Subnet & VLSM Calculator

A robust command-line IPv4 Subnet Calculator written in pure Python.

## 🚀 Features
- Input any CIDR (e.g., `192.168.1.50/26`).
- Outputs:
  - Network Address
  - Broadcast Address
  - Usable Host Range (First to Last Host)
  - Total Available Hosts & Usable Hosts
  - Subnet Mask & Wildcard Mask
  - Binary Representation of Mask and IP

## 💻 Usage
```bash
python subnet_calc.py 192.168.10.45/27
```
